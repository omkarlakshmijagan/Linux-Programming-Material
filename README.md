## 📖 About the Repository

This repository provides organized study resources for **Linux Programming**. It includes unit-wise lecture presentation PDFs, additional digital notes, and a combined presentation PDF to support classroom instruction, independent study, revision, and examination preparation.

> **Repository scope:** The currently available content consists of PDF learning materials. No executable programming assignments, shell scripts, source-code projects, or installation files are present in the repository at the time this README was prepared.

## 🎯 Learning Objectives

The course materials are intended to help learners:

- Build familiarity with Linux as a programming and command-line environment.
- Develop an understanding of concepts introduced across the five course units.
- Review lecture explanations and related course notes systematically.
- Prepare for assessments using the unit-wise resources.
- Connect course theory with hands-on Linux practice using a personal Linux installation or virtual machine.

*For the exact syllabus and topic sequence, refer to your institution's prescribed course syllabus and the linked lecture PDFs.*

## 🚀 Getting Started

### Option 1: View Resources Online

1. Open the [repository home page](https://github.com/omkarlakshmijagan/Linux-Programming-Material).
2. Navigate to **Digital Notes** and, for lecture materials, the **PPT** subfolder.
3. Select a PDF to view or download it.

### Option 2: Download the Entire Repository

From the repository page, select **Code → Download ZIP**, then extract the files.

### Option 3: Clone with Git

```bash
git clone https://github.com/omkarlakshmijagan/Linux-Programming-Material.git
cd Linux-Programming-Material
```

**Requirements to read the resources:** A PDF viewer or web browser. **Git** is only needed if you choose to clone the repository.

## 💻 Suggested Hands-on Learning Workflow

To complement the provided theory resources:

1. Read the lecture PDF for a unit.
2. Where available, study the matching digital notes.
3. Practice relevant Linux commands and programming concepts in a safe local environment.
4. Record commands, observations, and errors in a separate lab notebook.
5. Revise the unit before proceeding to the next one.

**Optional practice environment:** Ubuntu or another Linux distribution, a virtual machine, or Windows Subsystem for Linux (WSL). These are external tools suggested for personal practice; the repository does not contain their installers.
